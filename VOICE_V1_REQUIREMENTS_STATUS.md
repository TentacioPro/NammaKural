# Voice V1 checklist coverage and production gates

This matrix is deliberately candid: a testable interface or policy function is not a running model/media/database integration. `voice_v1` remains a development scaffold, not a production voice service.

| Area | Added in this branch | Still required before production claim |
|---|---|---|
| Realtime transport | Optional LiveKit/Coturn Compose fragment; explicit worker-adapter readiness gate | Working LiveKit browser client/worker, TLS, short-lived credentials, production Coturn external-IP/port/firewall config, ICE direct/TURN tests. The worker intentionally exits until actual adapters exist. |
| Audio provenance | `AudioFrame` with format/rate/channels/codec/sequence/monotonic time; strict validation and resampler protocol | Actual codec decode/resampling, device clock calibration, per-hop packet timing and signal-quality verification. Metadata cannot prove conversion happened. |
| AEC/NS/AGC and comfort noise | Device-processing flags are opt-in; comfort noise policy defaults off | Real DSP implementation, duplicate-processor detection from browser/device, noise-floor tuning and tests proving room tone never affects VAD/intelligibility. |
| VAD and endpointing | Slot-specific initial windows, confidence extension, EMA caller cadence policy; VAD and semantic turn-detector contracts; semantic confirmation required after acoustic candidate | Silero model/runtime and learned semantic turn detector implementation; replay-calibrated endpoint decisions and false-cut/latency tradeoff. |
| Interruptions and backchannels | Pause/resume state, context-gated acknowledgements, stop cue helper, epoch invalidation, TOOL_PENDING/HUMAN_HANDOFF guards, listening-cue threshold policy; async orchestrator cancels awaited adapter work on committed interruption and rejects stale output | Actual 250–350 ms classifier window, speech classification, media queue pause/resume/flush, provider-specific task cancellation, cue synthesis, false/missed interruption evaluation. |
| ASR and Tamil/Tanglish | Streaming ASR contract with timestamps/keyterms; transcript provenance and conservative versioned repair helper | Choose and connect a real streaming Sarvam or local IndicConformer/SraVaani runtime; dynamic keyterm session updates; noise/silence confidence calibration; dialect/code-switch benchmarks. Current text endpoint is not voice TTFA. |

## Test status

The isolated `voice_v1` tests cover frame metadata policy, endpointing functions, state transitions, speech normalization safety helpers, orchestration policy, playback metric validation, the injected async session pipeline/cancellation contract, and pure lifecycle rules. They do not test LiveKit, audio DSP, ASR/TTS quality, PostGIS runtime behavior, agency submissions, or authenticated staff access.

Run the focused suite:

```bash
pytest -q tests/test_voice_v1_*.py
```

**Acceptance bar for a sub-500 ms claim:** run the real WebRTC path with a measured end-of-user-speech timestamp and first audible playback acknowledgement on the same client monotonic clock; report p50/p90/p95/p99 by language, network/TURN path, hardware, model, and warm/cold state. Do not infer it from workflow timing, mocked providers, or interface-level tests.
